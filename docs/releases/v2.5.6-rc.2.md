JARVIS 2.5.6 RC2 adds updates inside the Android app.

- A dedicated cyan update popup presents the release's authored features and fixes.
- Download updates in the app, follow progress and install through Android's confirmation screen.
- Background update notifications and optional Wi-Fi downloads.
- Snooze, skip and manual checks under Settings → System → Updates.

The APK must retain the installed app's signing key. This first updater-enabled release uses the existing download link; future releases can be downloaded inside JARVIS. Android installation and physical-device acceptance must be validated before wider distribution. Foundation promotion remains subject to the existing acceptance gate.
