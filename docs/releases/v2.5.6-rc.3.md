JARVIS 2.5.6 RC3 adds live tool activity and safer execution.

- See tool names, approval waits, outcomes and elapsed time directly in chat.
- Expand longer phone/PC tasks and specialist work to follow progress and open Tasks or STOP.
- Reopen saved activity with the correct conversation; interrupted actions remain unconfirmed.
- Run independent reads concurrently within a bounded tool budget, and route clear volume/timer commands directly.
- Validate tool arguments and protect against duplicate or uncertain side effects.
- Keep screenshots on compatible model routes and match tools to available capabilities and permissions.
- Keep late receipts and verified PC screenshots attached to their originating reply.
- Review features and fixes and download future releases using the in-app updater introduced in RC2.

This release candidate retains existing approval and pairing gates. Clock intent
acceptance is not proof that an alarm or timer was saved. Stored activity is a
compact UI projection, separate from model history and task verification evidence.
