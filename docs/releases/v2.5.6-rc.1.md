JARVIS 2.5.6 RC1 brings the updated Android interface and shortcut setup.

- Cleaner home screen: removed the local-features banner and restored **Capabilities** in the bottom navigation.
- Personal shortcut bar: choose any of the available controls, reorder them, show labels, and swipe when they do not all fit.
- First-launch introduction: learn what each button does, then pick your shortcuts. Replay it from **Settings → Interface → Edit top bar**.
- Updated reading, step-by-step activities and gesture controls, including bookmarks, focused practice, action editing and clearer session controls.
- Preferences remain saved on the device, and the bottom navigation stays visible on narrow screens.

Install the attached **arm64 APK** on Android 7.0 or newer. This is a release candidate; physical-device acceptance and foundation promotion remain pending. The stable release channel is unchanged.

Local validation: 753 tests passed, 9 live-provider tests skipped, 10 protocol fixtures passed, and all 3 release-gate regression tests passed. TypeScript, lint and the web build passed. The release workflow also checks the source, builds the signed APK and runs native regression tests before publishing.
