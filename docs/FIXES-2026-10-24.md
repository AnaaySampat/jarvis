| Finding | Change |

Single-tool status comes from its actual receipt, including failed, blocked and unverified results. Native operator verification and approvals are unchanged. |
| Reviewer rejects fenced JSON / malformed replies | Accept a complete JSON fence and retry a malformed verdict once, with no tools. Invalid/outage results stay unverified. |

| Content false action claim | Allow directly rendered charts/tables/flowcharts/sample schedules; keep real external actions guarded. Document renderer block formats in the system prompt. |
| Unsaved calendar draft called saved | Only an actual event ID earns the saved claim; retain native “tap save” fallback text otherwise. |
| Running timer not cancelled | Use the resolved Clock app's own single timer notification Cancel action, verify removal, and otherwise open the timer list with explicit failure to stop automatically. Never choose between multiple timers or cancel unrelated notifications. |
| Renamed phone accepted as hardware model | Feed Android Build model/manufacturer/version into native observations; reject model claims missing the real model code. Read-only hardware queries can use this direct evidence without gratuitous screen taps, while still requiring independent completion verification. |
| Places endpoints fail | Add independently operated Private.coffee Overpass mirror to the bounded race and native HTTP allowlist; reject malformed responses. |
| Spotify direct query stays paused | Continue ordinary failed play-from-search requests through the existing native operator, verifying matching title/playback. Never widen restricted PC/WhatsApp tool scope. |
| Remote countdown resets to zero | Preserve duration on ACKs without it; track local expiry and refuse input after expiry. |
| Remote screen lost/stale | Clear stale video and control on loss, bound automatic fresh-session recovery to two attempts, cancel recovery on close, and restore the stream after a transient reconnect. |
| Android Back exits live view | Register the existing Android Back hook in RemoteDesktop; close via its normal stop/disarm path. |
