## Default Permission

Allows the JARVIS brain to drive the phone via the AccessibilityService.

#### This default permission set includes the following:

- `allow-is-enabled`
- `allow-observe`
- `allow-tap`
- `allow-tap-xy`
- `allow-long-press`
- `allow-double-tap`
- `allow-set-text`
- `allow-type-text`
- `allow-scroll`
- `allow-back`
- `allow-home`
- `allow-swipe`
- `allow-open-app`
- `allow-close-app`
- `allow-open-url`
- `allow-set-volume`
- `allow-read-clipboard`
- `allow-open-system-settings`
- `allow-open-accessibility-settings`
- `allow-speak`
- `allow-stop-speaking`
- `allow-poll-speaking`
- `allow-start-wake-word`
- `allow-stop-wake-word`
- `allow-poll-wake-word`
- `allow-show-stop-overlay`
- `allow-hide-stop-overlay`
- `allow-poll-stop-overlay`
- `allow-request-overlay-permission`
- `allow-get-device-stats`
- `allow-capture-screenshot`
- `allow-pick-folder`
- `allow-list-directory`
- `allow-read-file`
- `allow-clock-action`
- `allow-calendar-action`
- `allow-task-begin`
- `allow-task-checkpoint`
- `allow-task-finish`
- `allow-task-cancel`
- `allow-task-status`
- `allow-operator-start`
- `allow-operator-status`
- `allow-config-secret-set`
- `allow-config-secret-get`
- `allow-config-secret-delete`
- `allow-identity-info`
- `allow-identity-sign-auth`
- `allow-identity-sign-envelope`
- `allow-identity-sign-pairing`
- `allow-identity-verify-host-challenge`
- `allow-identity-verify-host-envelope`
